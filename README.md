# FindStar
FindStar 是一款面向个人资料整理与知识查找的桌面应用，将文件星图可视化与检索增强生成（RAG）相结合，帮助用户从浏览文件进一步走向理解和利用资料。作品设置资料库、星图探索、知识问答和设置四个板块，支持文件分类筛选、跨页全选、文本解析、图片本地预览及人工标签管理。星图通过大小不同的节点呈现分类层级，并以可查看依据的标签和关键词关联辅助探索。用户可在选定资料范围内进行本地关键词检索，也可接入大模型 API，根据检索到的内容生成带有来源引用的回答，并跳转查看原文。作品以简约界面、分层导航和轻量动画降低操作负担，探索文件管理、可视化浏览与可追溯问答相结合的个人知识利用方式。
