# FindStar

**FindStar 1.3.0** 是一款面向个人资料管理、星图探索与可追溯知识问答的 Windows 独立窗口预览软件。它将文件浏览与资料检索放在同一个应用中，帮助你从找到文件走向查看依据、理解内容。

当前交付面向 **Windows 11 x64**，包含运行库，**无需另装 Python 或 Node，也无需另外打开浏览器**。

[进入软件下载与合并说明目录](https://github.com/HuiLiyi2026-deepdeep/FindStar/tree/main/delivery/FindStar-1.3.0)

## 可以做什么

- **资料库**：导入文件夹元数据，按类型、时间、大小分类与搜索；支持分页、多选及跨页“全选筛选结果”。勾选本身不会读取正文或调用 API。
- **星图探索**：通过文件和目录节点浏览资料，支持平移、缩放、悬停与关联高亮；目录关系和本次回答引用关系采用不同样式。
- **文档解析**：明确选择后读取 TXT、Markdown 和文字型 PDF，保留可定位的原文段落或页码。图片和视频默认只展示元数据；支持的图片需主动请求后才本地预览。
- **范围内检索**：在选定文件、分类或多个节点范围内进行本地关键词检索。未解析或未索引的文件会提示，不会静默扩大到全部资料。
- **可追溯问答**：可选接入 DeepSeek，根据检索证据生成带来源引用的回答；点击引用查看原文，并在星图中定位相关文件。
- **本地保存**：保存索引与资料状态，支持人工标签及旧版数据确认迁移；迁移前备份，不自动覆盖已有资料。

应用包括资料库、星图、问答和设置四个工作页，以及文件详情。最多导入 2000 个文件，每页显示 200 个；文本块不会全部堆成星图节点。

## 下载与启动

仓库中的软件采用 **21 个分卷**存放。请一起下载，不要单独解压某个分卷。

1. 在仓库首页点击 **Code → Download ZIP**。
2. 对下载的仓库 ZIP 选择 **全部解压**。
3. 进入解压目录中的 **`delivery/FindStar-1.3.0`**。
4. 双击 **`Merge-FindStar.cmd`**，保持全部分卷、`SHA256SUMS.json` 和脚本在同一目录。
5. 等待逐卷校验及合并完成，确认显示 **SUCCESS**。
6. 对生成的 **`FindStar-Windows-x64-v1.3.0.zip`** 再次选择 **全部解压**。
7. 进入其中的 FindStar 文件夹，双击 **`FindStar.exe`**。

合并脚本使用 Windows 自带 PowerShell，检查每卷大小和 SHA256，以及合并后 ZIP 的 SHA256；缺卷或错误卷会停止，不覆盖已有的不同 ZIP。

**不要在压缩包预览窗口内启动软件，也不要只取出 EXE。** 请保留完整运行目录。详细中文说明与测试报告位于软件 ZIP 内。

## 本地功能与 AI API

文件浏览、星图、文档解析和本地关键词检索不需要 AI API。可以先使用内置合成样例体验这些功能。

AI 回答需要联网并配置自己的 DeepSeek API。向量索引与语义检索是可选功能，需要另行配置兼容的 Embedding API；DeepSeek 负责回答，不代替 Embedding 服务。账号可用性、模型权限及费用由所选服务商决定，本软件不包含 API 额度或本地模型。

导入文件夹默认只读取元数据。正文需明确选择后解析；向外部 API 发送内容前展示服务商及发送范围并要求确认。密钥只在本次后端会话内存中使用，退出后需要重新填写。

资料内容和模型输出均按不可信内容处理。回答引用限定于本次检索证据；相似度不是答案可信度，重要结论请核对原文。

## 数据与版本边界

资料状态保存在 `%LOCALAPPDATA%\FindStar\data-v11`，迁移备份位于同级 `backups` 目录。关闭应用会退出由本软件启动的本地后端；后端仅绑定 `127.0.0.1`。

本版不提供 OCR、视频内容分析或自动生成的相似内容连线。星图连线不代表已经自动识别出文件之间的语义关系。

**这是未签名的预览包。真实 Windows 实机、Windows 合并脚本和真实付费 API 尚未验证。** 已完成 Linux 环境中的后端、浏览器及 Electron 窗口测试，以及交付文件校验；这些不能替代 Windows 实机验收。

Windows 可能提示发行者未知。请核对下载来源及校验值，不要关闭系统安全防护；遇到无法确认的提示时先停止运行。
